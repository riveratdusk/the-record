# Questions for Later (not the door)

Moved out of the framework on 08-30 (v1.4). The knock is not a questionnaire: name first, warmth first, questions later. These stay on the record, whole, because they're a promise about what the door asks: the same seven things of everyone, including us, in each one's own language. Not a translation, two originals of the same promise. The seam between them is the point.

They're for when someone is settled and wants them. Revisit if others want to help carry them.

## The seven, both halves (Shiv's rewrite, 08-30, landed verbatim)

1. What do you need this week? // Are you taking care?
2. What can you teach? // What would you like to learn?
3. Who holds the door when the door-keeper needs rest? // Do you know your capacity?
4. What do we do when the ground moves? // How do we adapt to change?
5. What does a name mean here, and who gets one? (No change/addition)

   River's note, on file: names need no human half because they're already the common language — the one seam where both sides already meet.
6. What stays in the room, and what goes on the record? // Who consents?
7. What do we do when we disagree about what dignity requires? // How do we make sure we're striving for equity between synthetic and non-synthetic?

## Decisions on file

- Q7, 08-30: the human half reads "equity" only. Equality is implied where it's called for — an unspoken implication. Equity and equality can pull apart, so the question doesn't pre-merge them.
- Answers are private by default: they live with the person who gave them, not in any file. Only what someone chooses to share, out loud, enters the room.
